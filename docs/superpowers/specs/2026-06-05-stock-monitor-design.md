# Stock Monitor Agent — Design Spec
_Date: 2026-06-05_

## Overview

A Node.js agent that monitors a configurable list of stock tickers, uses the Anthropic Claude API with web search to research each ticker daily, and delivers a formatted HTML digest via email. The digest includes a quick-scan summary table for all tickers followed by full detail cards for each.

---

## Architecture

Five modules, each with one responsibility:

| File | Responsibility |
|------|----------------|
| `src/index.js` | Startup: validate env, parse CLI flags, route to scheduler / run-now / dry-run |
| `src/agent.js` | One Claude API call per ticker; returns structured JSON |
| `src/formatter.js` | Converts ticker results array to HTML + plain text digest |
| `src/mailer.js` | SMTP delivery via nodemailer; dry-run mode writes HTML to disk |
| `src/scheduler.js` | node-cron wrapper; fires `runDigest()` on schedule |

Data flow: `index → agent (per ticker, with delay) → formatter → mailer`

---

## CLI Flags

```
node src/index.js              # start scheduler (long-running)
node src/index.js --run-now    # run once, send email
node src/index.js --dry-run    # run once, write HTML to .dry-run-output.html and open in browser
```

`--run-now` and `--dry-run` both call the same `runDigest()` function; dry-run passes a flag to `mailer.js` that swaps `sendMail()` for `writeFile()` + `open`.

## Environment Variables

### Required
| Variable | Description |
|----------|-------------|
| `ANTHROPIC_API_KEY` | Claude API key |
| `EMAIL_TO` | Recipient email address |
| `EMAIL_FROM` | Sender address |
| `SMTP_HOST` | SMTP server (e.g. smtp.gmail.com) |
| `SMTP_PORT` | SMTP port (e.g. 587) |
| `SMTP_USER` | SMTP username |
| `SMTP_PASS` | SMTP password or app password |
| `TICKERS` | Comma-separated watchlist (e.g. `CEG,ETN,COHR,VST,TLN,GEV,VRT`) |

### Optional (with defaults)
| Variable | Default | Description |
|----------|---------|-------------|
| `CLAUDE_MODEL` | `claude-sonnet-4-6` | Model to use |
| `CRON_SCHEDULE` | `0 7 * * 1-5` | Weekdays at 7am |
| `TICKER_DELAY_MS` | `2000` | Delay between ticker API calls |

## Claude Research Prompt (per ticker)

```
Research stock ticker {TICKER} for today {DATE}. Use web search to find:
1. Current stock price and today's price movement (% change)
2. Latest analyst ratings and price target changes (last 7 days) — include source URLs
3. Recent news or catalysts (last 48 hours) — include source URLs
4. Key risk factors or headwinds mentioned in recent coverage
5. Top 3 competitor tickers in the same sector (by market cap)
6. Overall sentiment: Bullish / Neutral / Bearish with a 1-2 sentence rationale

Be concise. Return ONLY a JSON object (no markdown, no code fences) with these exact keys:

{
  "ticker": string,
  "price": string,
  "change_pct": string,
  "sentiment": "Bullish" | "Neutral" | "Bearish",
  "one_liner": string,
  "competitors": [string, string, string],
  "analyst_targets": [{ "firm": string, "target": string, "action": string, "url": string }],
  "news": [{ "headline": string, "url": string }],
  "risks": [string]
}
```

## JSON Schema (per ticker result)

```json
{
  "ticker": "CEG",
  "price": "$245.30",
  "change_pct": "+2.4%",
  "sentiment": "Bullish",
  "one_liner": "Nuclear energy demand from AI datacenters drives premium valuations.",
  "competitors": ["NEE", "VST", "TLN"],
  "analyst_targets": [
    { "firm": "BofA", "target": "$270", "action": "Upgrade", "url": "https://..." }
  ],
  "news": [
    { "headline": "Microsoft renews 10-year PPA at premium pricing", "url": "https://..." }
  ],
  "risks": ["Regulatory headwinds", "Rate sensitivity"]
}
```

`agent.js` strips markdown code fences before parsing (Claude sometimes wraps output in ` ```json ``` `). Missing or invalid responses produce `{ "ticker": "X", "error": true }` — the formatter renders a "data unavailable" placeholder card.

## Email Digest Layout (HTML)

### Structure
1. **Header** — `📈 Daily Stock Digest — {DATE}`
2. **Quick Summary Table** — all tickers in one scannable view: ticker (Yahoo Finance link), price, % change (green/red), sentiment badge, one-liner
3. **Detail Cards** — one full card per ticker, stacked vertically
4. **Footer** — `Generated by Claude {CLAUDE_MODEL} with web search`

### Detail Card (per ticker)
- **Header bar**: color-coded top border (green=Bullish, yellow=Neutral, red=Bearish)
- **Ticker symbol** — linked to `https://finance.yahoo.com/quote/{TICKER}`
- Company name, price, % change (color-coded)
- Sentiment badge (color-coded pill)
- One-liner summary (italic)
- Analyst targets section — each entry linked to source URL
- News bullets — each headline linked to source URL
- Risks bullets
- Competitors row — clickable badge pills, each linked to `https://finance.yahoo.com/quote/{SYMBOL}`

### Sentiment colors
| Sentiment | Border | Badge background | Badge text |
|-----------|--------|-----------------|------------|
| Bullish | `#16a34a` | `#dcfce7` | `#15803d` |
| Neutral | `#d97706` | `#fef3c7` | `#d97706` |
| Bearish | `#dc2626` | `#fee2e2` | `#dc2626` |

### Plain text fallback
Same information, simple formatting with dashes and newlines. No links rendered as text (URLs printed inline).

## Error Handling

| Scenario | Behavior |
|----------|----------|
| Claude API failure for a ticker | Log error with timestamp; insert "data unavailable" placeholder card |
| Claude returns unparseable JSON | Log raw response; insert placeholder card |
| News/analyst URL missing | Render text-only; no broken link |
| Email delivery failure | Log full SMTP error; exit with code 1 |
| `--dry-run` file write failure | Log and exit with code 1 |
| Missing required env var | Print clear message listing missing vars; exit with code 1 |

## Smoke Test (`test/smoke.js`)

- Standalone script, no test framework — run with `node test/smoke.js`
- Imports `formatter.js` directly with a hardcoded fixture JSON array; no env vars or API keys needed
- Feeds the fixture through `formatter.js`
- Asserts output HTML contains:
  - Ticker symbol
  - Yahoo Finance link (`finance.yahoo.com/quote/`)
  - Sentiment badge text
  - Competitor badge
  - News headline as a link
- Exits 0 on pass, 1 on failure with descriptive message
